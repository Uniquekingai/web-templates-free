مدیریت هوشمند محصولات ووکامرس با هوش مصنوعی | AI-powered WooCommerce product management

== Description ==

یک AI Agent کامل برای مدیریت محصولات ووکامرس با رابط کاربری مکعبی زیبا.

ویژگی‌ها:
- طبقه‌بندی هوشمند محصولات توسط AI
- تغییر قیمت تکی و گروهی از طریق چت
- ویرایش نام و توضیحات محصول
- پشتیبانی از فارسی و انگلیسی
- پیشخوان مکعبی با طراحی دارک مدرن
- انتخاب گروهی و عملیات دسته‌جمعی
- جستجوی سریع محصولات
- پروتکل امن AJAX + nonce

== Installation ==

1. پلاگین را از Plugins > Add New > Upload Plugin آپلود کنید
2. فعال‌سازی کنید
3. به AI Agent > تنظیمات بروید
4. کلید API کلود خود را از console.anthropic.com وارد کنید
5. به AI Agent بروید و شروع کنید!
