
# 🔐 Animated Login Section


A modern and interactive **login section** with a smooth hover animation.

When the user hovers over the **Login button**, the username and password fields appear with a clean and engaging transition, creating a dynamic user experience.

### ✨ Features

* 🎯 Hover-based interaction
* 💡 Smooth and modern animation
* 🌙 Dark UI design
* ⚡ Lightweight and fast
* 📱 Fully responsive

---

### 🚀 How It Works

* Initially, only the **Login button** is visible
* On hover, the login form expands
* Username & password fields appear smoothly
* Creates a clean and futuristic UI effect

---

### 💡 Use Cases

* Landing pages
* Modern web apps
* UI inspiration
* Creative login systems
